# 大家來找茶｜茶葉知識小遊戲

國立暨南國際大學 115-1 非營利組織第二組「大家來找茶」製作的茶葉知識推廣網頁遊戲，非營利用途。
跟著茶葉精靈「薩姆」，用六個關卡認識茶：

1. 六大茶類
2. 台灣名茶產地
3. 日月潭紅茶四大品種
4. 熱泡實作（秤茶、選水溫、注水、計時出湯）
5. 回沖與冷泡
6. 茶的小常識

純靜態網頁，不需要安裝或登入；進度存在瀏覽器。內容都在 `js/data.js`，要修改文字改這個檔案即可。

## 資料來源

- 日月潭紅茶四大品種：《第一屆日月潭飲食生活節》手冊，魚池鄉公所，2024
- 沖泡方式：HOHOCHA 喝喝茶（台灣香日月潭紅茶廠）沖泡說明
- 茶類、名茶產地與小常識：一般茶葉常識整理
- 音樂與音效：見 `audio/CREDITS.txt`（皆為 CC0）
